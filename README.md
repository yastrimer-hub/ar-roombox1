# AR для киберпанк-ромбокса — пошаговая инструкция

Всё бесплатно, без установки приложений. Работает в браузере телефона (и на Android, и на iPhone) — просто наводишь камеру на фасад ромбокса, и на нём появляются анимации.

Как это работает: QR-код — это просто ссылка на веб-страницу. Страница через камеру браузера **распознаёт сам фасад ромбокса** как изображение-маркер (это называется image tracking) и рисует поверх него анимацию. Это НЕ распознавание QR-кода как картинки — QR только открывает страницу один раз.

---

## Что в архиве

- `index.html` — сама AR-страница (камера + анимация)
- `assets/car.svg`, `assets/person.svg` — простые неоновые силуэты-заглушки (машина и люди). Замени на свои картинки, когда будет время — просто перезалей файл с тем же именем.
- `qr-generator.html` — отдельная страничка, которая сама генерирует QR-код под финальную ссылку (работает офлайн в браузере, ничего не надо мне присылать)
- `targets.mind` — этого файла пока нет, его нужно сделать по шагам ниже (шаг 2)

---

## Шаг 1. Сфотографируй фасад ромбокса как "маркер"

Это ключевой момент. Нужна одна хорошая фотография фасада (той стороны, куда будут наводить камеру), при **том же освещении**, в котором люди будут сканировать.

Советы:
- Свет должен быть стабильный — сильно мигающие неоновые led лучше на секунду притушить/сделать статичными на момент съёмки, иначе трекер будет "путаться".
- Снимай прямо, без сильного перекоса, при хорошем разрешении.
- Чем больше на фасаде мелких деталей (вывески, знаки, текстуры) — тем лучше цепляется трекинг. У тебя их полно, это плюс.

## Шаг 2. Сделай файл targets.mind (бесплатный онлайн-компилятор)

1. Открой на телефоне или компьютере: **https://hiukim.github.io/mind-ar-js-doc/tools/compile/**
2. Загрузи туда фото фасада из шага 1.
3. Нажми "Start", подожди — он покажет, сколько "фич" (точек привязки) нашёл. Чем больше — тем стабильнее трекинг.
4. Скачай получившийся файл `targets.mind`.
5. Положи `targets.mind` в ту же папку, где лежит `index.html` (рядом, не в подпапку).

## Шаг 3. Бесплатный хостинг через GitHub Pages

1. Зарегистрируйся на **github.com** (если ещё нет).
2. Создай новый репозиторий, например назови `ar-roombox`.
3. Загрузи туда все файлы: `index.html`, `qr-generator.html`, папку `assets/`, и `targets.mind` из шага 2. Это можно сделать прямо в браузере — кнопка "Add file → Upload files" на странице репозитория.
4. Зайди в **Settings → Pages**, в разделе "Build and deployment" выбери "Deploy from a branch", ветку `main`, папку `/ (root)`, сохрани.
5. Через пару минут GitHub покажет ссылку вида:
   ```
   https://твой-логин.github.io/ar-roombox/
   ```
   Это и есть твой рабочий адрес — открой его в телефоне, разреши доступ к камере, наведи на фасад.

## Шаг 4. Сделай QR-код на готовую ссылку

Есть 2 варианта:

**А) Через свою страничку (без интернета, без меня):**
Открой `https://твой-логин.github.io/ar-roombox/qr-generator.html`, вставь туда финальную ссылку из шага 3, нажми "Сделать QR", скачай PNG.

**Б) Просто скажи мне финальную ссылку** — сгенерирую QR прямо в чате.

Готовый QR распечатай или выведи на маленький экранчик рядом с ромбоксом.

---

## Как это будет выглядеть у зрителя

1. Сканирует QR обычной камерой телефона → открывается страница.
2. Жмёт "Запустить камеру", разрешает доступ.
3. Наводит на фасад ромбокса пару секунд.
4. Поверх появляется машина, катающаяся по улице, и силуэты людей у дверей — прямо на реальном видео с камеры.
5. Можно отходить/приближаться — трекинг держится за сам фасад, а не за QR.

## Что доработать дальше (когда будет время)

- Заменить `car.svg` и `person.svg` на свои рисунки в том же стиле, что и ромбокс (можно нарисовать в любом бесплатном векторном редакторе типа Figma/Inkscape, главное — сохранить с тем же именем файла).
- Добавить больше анимированных слоёв (ещё машины, летающие дроны, мигающие вывески) — просто копируешь блок `<a-image>` в `index.html` и меняешь позицию/картинку/скорость.
- Если камера "теряет" фасад из-за бликов LED — можно приглушить яркость подсветки именно в момент, когда снимаешь фото для `targets.mind`, и оставить его умеренным при обычном просмотре.
- Если захочешь честный объём (3D-модели машин/людей, не плоские спрайты) — тот же MindAR поддерживает `.glb` 3D-модели вместо картинок, бесплатные модели можно взять на **sketchfab.com** (фильтр "Downloadable" + лицензия CC).

Если что-то не срабатывает на каком-то из шагов — присылай скриншот/ошибку, разберёмся вместе.
